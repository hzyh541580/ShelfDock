# 拾放 ShelfDock

独立开发的 Windows 拖放暂存工具，与 Yoink 无关联。当前源码版本为 1.21。

## 使用

运行环境：Windows 10 / 11，.NET Framework 4.8。安装器和便携程序通过 Releases 分发。

## 构建

在 Windows PowerShell 中进入 src 文件夹，运行 `./build.ps1`。脚本调用 Windows .NET Framework C# 编译器，运行自动检查并生成程序和安装器。无需第三方 NuGet 包。

## 1.21 边缘唤出误触修复

只有拖动文件、文件合集、文字或图片等受支持的真实内容到所选边缘范围时才唤出窗口。普通点击、长按和按住鼠标移动不会唤出窗口。保留边缘方向、比例阈值、渐显渐隐及原有关闭设置。

## 1.2 最后一项移除后自动收起

最后一个文件或合集被 × 移除后，立即按设置中的延迟开始计时，无需等待鼠标离开窗口。可选择立即、0.5、1、1.5、2 秒，时间到后渐隐收起，程序继续运行。还有其他项目时保持显示；新增内容会取消收起。

## 1.19 拖放修复

- 修复从 Windows 资源管理器拖入文件或文件合集失败的问题。
- 主程序检测到管理员权限时，自动以当前桌面的普通用户权限重启，允许普通权限的资源管理器正常拖放到窗口。
- 安装完成后也以普通用户权限启动主程序；安装器和卸载器仍按需申请管理员权限。
- 保留同一次拖入多个文件或文件夹组成合集的行为，不创建真实文件夹。
- 安装版默认安装到 `C:\Program Files\ShelfDock`，目录内提供带界面的 `Uninstall.exe`。

“完全卸载”会删除安装文件、本账户的设置、暂存记录、缓存、快捷方式、开机启动项和应用注册表项。暂存列表引用的外部原文件不会删除。

## 数据

个人数据位于 `%LOCALAPPDATA%\ShelfDock`；文件暂存仅记录原文件路径。迁移原文件需另行处理。
